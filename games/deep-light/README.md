# 云下矿团 · Below the Clouds

独立原创的卡通地底冒险，受到经典浏览器采矿游戏的节奏与探索乐趣启发。角色、插画、地图生成、敌人、剧情、名称和音效均为本项目创作。入口保留 `/games/deep-light/`，可直接由 GitHub Pages 提供静态文件。

小芒和灯笼机器人阿零落在失去风的矿站。挖出矿物，向浣熊机械师老狸购买装备，点亮地下驿站，带回三枚风印，让云海重新流动。

## 内容

- 64 × 148 格可开采世界，五种地层、矿洞、熔流、毒雾、信匣及旧城回信。
- 八种矿物，独立售价与重量；普通土、石板、玄岩、黑曜岩与不可开采基座。
- 五条装备升级线，每条五级：钻头、氧气瓶、矿袋、护具、喷气背包。
- 五种消耗道具：急救包、氧气胶囊、岩爆球、风铃信标、探矿声呐。
- 七种地底生物，三名拥有不同攻击模式的守卫，最终守卫需要前两枚风印。
- 四座驿站：点亮后免费补给，可在矿站与驿站之间传送。
- 六个自动结算的委托，五封旧城回信，以及可继续探索的结局。
- 自动救援保留装备与委托，损失部分矿物及金币。
- 三个本机存档位，十秒自动保存、手动保存、JSON 备份导出和校验导入。

## 操作

| 操作 | 键位 |
| --- | --- |
| 左右移动与横向挖掘 | ← → / A D |
| 向下挖掘 | ↓ / S |
| 喷气飞行 | ↑ / W |
| 挥钻攻击 | 空格 |
| 商店、信匣、驿站交互 | E |
| 五种道具 | 1–5 或点击道具栏 |
| 暂停 | P / Esc |

手机与窄屏提供触屏方向键、攻击和交互按钮。钻头过热时松开方向键散热；悬空时不能横向挖掘，也不能向上挖掘。短按方向按钮的进度保留一秒，以便连续点按。

## 开发与验证

原生 ES modules、Canvas 2D、SVG 和 Web Audio；无外部依赖、构建流程或 Flash 运行时。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test games/deep-light/tests/engine.test.mjs
```

从仓库根目录运行，预览地址 `http://127.0.0.1:8765/games/deep-light/`。

- `data.mjs`：内容、装备、矿物、委托、剧情。
- `engine.mjs`：确定性地图、模拟、经济、战斗、救援、存档验证。
- `render.mjs`：原创 Canvas 角色、地层、矿站、怪物、守卫与地图绘制。
- `app.mjs`：键盘与触屏输入、对话框、商店、存档、音效。
- `assets/`：原创 SVG 封面、角色头像和图标。
- `tests/engine.test.mjs`：采矿、经济、冒险、战斗和存档行为测试。

存档键为 `cloud-miners-v3`，保存在当前浏览器中。不同设备之间使用备份导入导出。导入会验证地图、角色、装备、道具与探索记录。此前的 Flash 兼容版本使用不同的存档格式。
