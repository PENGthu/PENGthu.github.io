# 地心寻光 · Deep Light

原创像素挖矿冒险，玩法灵感来自 [4399 在 2009 年上线的《挖地小子》](https://www.4399.com/flash/12954.htm)：挖掘、卖矿、装备升级、氧气管理、特殊矿石与地底首领。本游戏的代码、角色、场景、文字和音效均为独立创作，不使用原游戏 Flash 或资源。

纯 HTML / CSS / ES modules / Canvas 2D，无运行时依赖、无需构建，兼容此仓库现有 GitHub Pages / Jekyll 发布方式。访问 `/games/deep-light/` 即可运行。

## 玩法

- 方向键 / WASD：长按移动与挖掘，向上使用喷气装备，松开在空洞中会下落。也可以点击角色上下左右的场景完成一步挖掘，手机方向键支持轻点与长按。
- 空格：钻头近身攻击。1：炸弹；2：便携氧气；3：带矿石回城。
- 地表按 E 打开商店，卖矿、升级钻头 / 氧气瓶 / 矿袋 / 护甲。生命与氧气在营地免费补满。
- Ⅱ级钻头可以开采玄武岩，Ⅲ级可以开采黑曜石。炸弹也能炸开岩层。
- 寻找 116m、240m、356m 的三枚晶核，解除地心守卫的护盾，击败守卫，抵达 444m 的信标救回阿岚。
- P / Esc 暂停。切换标签或应用时自动暂停。手机有长按方向键与攻击键。
- 每 10 秒、本次交易 / 道具使用、暂停和离开页面时写入 `localStorage`。每个浏览器仅保留一个冒险；重新开始需确认。受限制的浏览器会提示存档不可用。
- 倒下会被救援带回营地，损失未出售矿石和 10% 金币，保留装备、已挖开的地图及晶核。

## 开发与验证

在仓库根目录启动静态服务：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8767/games/deep-light/`。模块需要 HTTP 服务，不能以 `file://` 打开。

```sh
node --test games/deep-light/game.test.mjs
```

测试覆盖随机地图目标可达性、挖矿交易、容量、升级门槛、道具、救援、首领护盾与胜利、存档完整性。添加 `#debug` 可暴露 `window.deepLight`，供开发工具检查模拟状态。

文件：`engine.mjs` 纯模拟，`render.mjs` 过程绘制像素场景，`app.mjs` 输入与界面，`style.css` 响应式布局，`icon.svg` 图标。
