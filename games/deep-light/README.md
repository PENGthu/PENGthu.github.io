# 挖地小子 · 空 — 原版浏览器兼容版

本页面运行联众 / OurGame 的原版 Flash 游戏内容。参考 [4399 原版游戏页](https://www.4399.com/flash/12954.htm)，保留原作的画面、角色、中文剧情、地图、矿石、装备、道具、怪物和双结局。

## 原版内容与兼容修复

- 本体和中文资源取自 4399 旧版游戏加载器指向的公开资源。
- 全部 11 段开场 / 剧情 / 转场动画与两种结局动画随页面一同部署，游戏内不依赖第三方服务器。
- 原版在线保存接口失效；采用 [MHHF 档案](https://www.mhhf.com/game/play/5450) 中的本机保存修复代码。2397 个 SWF 数据块中只替换 12 块（7 块中文字体名称 / 文本绑定、1 块存档按钮、4 块 ActionScript 兼容代码），其余 2385 块逐字节保持不变。图形、动画与地图保留原版数据；中文资源的保存成功提示为本机存档修复者 PolarZero 署名，旧域名校验另补上本 GitHub Pages 域名（仅替换两处等长域名字符串）。
- 兼容代码使用 Flash SharedObject，由 Ruffle 保存在浏览器本机。旧版 4399 账号、积分排行榜与勋章服务器功能不提供。
- 使用官方 [Ruffle 0.6.0](https://github.com/ruffle-rs/ruffle/releases/tag/v0.6.0) 运行环境，文件随站点部署，不要求安装 Flash 插件。

原始资源地址、文件大小、SHA-256 和变更清单记录在 `original/provenance.json`。`tools/build-compat.py` 与 `tools/build-resource-compat.py` 可以从指定哈希的官方本体和本机保存档案复现兼容修复。

## 操作

方向键移动和挖掘，↑ 使用飞行器。无法向上挖掘；悬空时不能向左右挖掘。走到地表商店门口自动进入商店；点击画面右侧「包」查看装备和背包。将道具拖到顶部 A / S / D / F / G 栏后按相应字母使用。

在原版商店中点击「保存」，下次在原版菜单选择「继续游戏」。存档属于当前浏览器和站点；更换设备、浏览器或清除站点数据不会保留它。右键游戏画面打开 Ruffle 存档管理，可下载备份。

页面支持暂停、声音开关、保持 4:3 比例的全屏及触屏键盘。触屏兼容与浏览器性能因设备而异，原版主要面向键盘和鼠标。

## 本地预览

使用任意静态 HTTP 服务器打开本目录。直接通过 `file://` 打开无法正常加载 WebAssembly。GitHub Pages 使用相对资源路径即可运行。

`ruffle/` 保留 Ruffle 的 MIT 与 Apache 2.0 许可证；原版游戏作品署名归联众 / OurGame。

## 验证记录

已在现代浏览器验证原版标题、新游戏菜单、三段教程、开场与第一任务剧情、第一矿区、中文商店与装备列表、保存成功、重新载入后的继续游戏，以及存档管理器识别本机记录。页面的暂停 / 恢复、声音开关、全屏 / 退出全屏、390px 手机布局和触屏移动均已检查。

`python3 tools/verify-assets.py` 校验全部 15 个 SWF 文件的哈希、格式与长度，并从中文资源中的剧情定义核对所有 13 段外部剧情 / 结局文件均随站点部署。尚未逐关通关验证所有首领与结局分支。
