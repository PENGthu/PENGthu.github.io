# 九顿 · 下潜

以广西都安九顿天窗为原型的洞穴潜水模拟。纯静态、无构建依赖，入口为 `index.html`，由现有 GitHub Pages / Jekyll 直接发布。

洞穴剖面为示意，非真实测绘；减压与氧中毒模型经过简化。**不能用于真实潜水计划。**

## 功能

- 三份潜水计划：天窗水潭（空气，0–30 m）、洞口平洞（Tx 21/35 + EAN50，45 m）、竖井 120（Tx 10/70 + 旅行气 + EAN50 + 氧气）。
- 沿引导绳下潜/上升，三档游速；时间流速 ×1–×180，出现危险自动回到 ×1。
- Bühlmann ZHL-16C（氮、氦）+ 梯度因子：实时减压上限、免减压时间、完整出水计划与气量是否足够。
- 氧分压、CNS 氧时钟、缺氧、等效麻醉深度（氮醉）、耗气、三分之一规则、上升速率。
- 洞穴环境：深度与洞内的光照衰减、手电视野、狭窄段扬沙。
- 剖面全图、浏览器自动存档、结束复盘清单；键盘与触屏操作。

## 文件

| 文件 | 作用 |
|---|---|
| `cave.mjs` | 洞穴剖面数据与沿引导绳插值 |
| `engine.mjs` | 纯模拟：组织饱和、气体、事件、结局，不访问 DOM |
| `render.mjs` | Canvas 2D 剖面渲染 |
| `app.mjs` | 输入、界面、主循环、存档 |

## 本地运行

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/games/jiudun-dive/`。ES modules 需要 HTTP 服务，不能使用 `file://` 直接打开。

模型检查：

```sh
node --test games/jiudun-dive/engine.test.mjs
```

## 模型边界

淡水 (0.0981 bar/m)、海平面、恒定表面耗气率。梯度因子低值锚定在出现过的最深 GF 低值上限。CNS 采用 NOAA 单次暴露限值，1.6 以上按指数外推。扬沙、能见度、灯电量为游戏数值。真实事故与人物未写入模型。
