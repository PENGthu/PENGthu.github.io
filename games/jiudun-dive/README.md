# 九顿 · 下潜

以广西都安九顿天窗为原型的 2D 洞穴潜水游戏。纯静态、无构建依赖，入口为 `index.html`，由现有 GitHub Pages / Jekyll 直接发布。

洞穴剖面、人物和事件都是虚构的；减压与氧中毒模型经过简化。**这是娱乐内容，不是潜水教学，不能用于真实潜水计划。**

## 玩法

- 侧视剖面，自由游动（WASD / 方向键），鼠标控制手电方向；手机上左侧拖动游动、手电跟随方向。
- 自己放线：靠近岩壁按 R 系主线，游动时线轮自动放线、绕过拐角；接上永久线后按住空格抓线、沿线走。永久线上的箭头指向出口。
- 泥沙：贴底游或 Shift 大踢腿会把细泥踢起来，泥在水里扩散、几分钟才落下；能见度跟着变差，手电光被泥吃掉。
- 窄口：侧挂瓶会让身体变宽。85 米限制段要先按 G 把瓶子放在线上，或者连按 F 扭动挤过去，回程按 E 挂回。
- 气体：底气三分之一返航；按 X 或数字键换气，注意低氧底气和减压气的深度范围；打空了会自动换到下一瓶可用的气。
- 减压：Bühlmann ZHL-16C（氮、氦）+ 梯度因子，实时减压上限和出水时间。按住 Q 停下调整呼吸，时间加快，适合等减压。
- 压力：黑暗、离线、卡住、低气压会让人紧张，耗气变快；太紧张会惊慌乱游。氮醉让人觉得一切都挺好。
- 出事或出水后生成复盘：剖面图上的轨迹、编号的时间线、八项检查，以及带出水的东西。

三个任务：天窗水潭（空气，训练）、洞口平洞（Tx 21/35 + EAN50，会落泥）、竖井 120（Tx 10/70 + 三瓶减压气，限制段和灯具故障）。

## 文件

| 文件 | 作用 |
|---|---|
| `cave.mjs` | 洞穴形状（SDF）、永久线、地名、泥沙与日光网格 |
| `missions.mjs` | 任务、装备、目标、事件 |
| `sim.mjs` | 纯模拟：游动与碰撞、放线与抓线、泥沙、呼吸、减压、紧张、复盘数据，不访问 DOM |
| `deco.mjs` | 减压与气体模型 |
| `render.mjs` | Canvas 2D：岩石贴图、水、日光、手电光锥、泥沙、线、潜水员、测绘图 |
| `app.mjs` | 输入（键盘、鼠标、触屏）、HUD、界面、复盘、本地存档 |

## 本地运行

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/games/jiudun-dive/`。ES modules 需要 HTTP 服务，不能使用 `file://` 直接打开。

测试：

```sh
node --test games/jiudun-dive/game.test.mjs
```

在地址后加 `#debug` 会暴露 `window.jiudun`，可以读写模拟状态，便于调试。
