# 方舟动物园 · 网页同人版

桌游《方舟动物园》（Ark Nova）的网页复刻版：建造动物园、引进动物、结交合作伙伴、支持野生动物保护项目。`index.html` 是构建好的单文件页面，源码在 [PENGthu/slayspire 的 ark-nova 目录](https://github.com/PENGthu/slayspire/tree/ccr-24e97f54-5j5rx4/ark-nova)。

- 复刻原作基础游戏的规则、10 张地图与全部卡牌功能：128 张动物、64 张赞助卡、32 个保护项目、11 张终局计分卡
- 1–4 人（另有 5 人扩展）：每个座位可以是人类或 AI（简单 / 普通 / 困难），可以同屏轮流，也可以用各自的设备联机
- 单人挑战：原版单人规则，6 轮，可选难度
- 进度自动保存在本机浏览器，支持电脑与手机

粉丝自制的非商业作品，复刻原作（Mathias Wigge 设计，Feuerland Spiele 出版）的规则与卡牌功能；卡牌文字为本作撰写，插图为自绘，与原作出版方无关。喜欢的话请支持正版桌游。
