# 方舟动物园 · 网页同人版

桌游《方舟动物园》（Ark Nova）的网页还原版：建造动物园、引进动物、结交合作伙伴、支持野生动物保护项目。`index.html` 是构建好的单文件页面，源码在 [PENGthu/slayspire 的 ark-nova 目录](https://github.com/PENGthu/slayspire/tree/ccr-24e97f54-5j5rx4/ark-nova)。

- 1–4 人：每个座位可以是人类或 AI（简单 / 普通 / 困难），多名人类玩家可以同屏轮流
- 单人挑战：在第 5 次休息结束前让吸引力与保护点数两个标记相遇
- 5 张行动卡轮转、六边形动物园地图、134 种动物、64 张赞助卡、32 个保护项目、7 张地图
- 进度自动保存在本机浏览器，支持电脑与手机

粉丝自制的非商业作品，规则结构参考原作（Mathias Wigge 设计，Feuerland Spiele 出版），卡牌数值与美术均为原创的简化表现，与原作出版方无关。
