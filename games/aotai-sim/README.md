# 鳌太 · 每一步

一款纯静态、无构建依赖的山地决策模拟游戏。入口为 `index.html`，可以直接由现有 GitHub Pages / Jekyll 发布。

角色、抽象节点和数值均为虚构。模型用于观察天气、保温、体力、补给、团队与救援之间的因果，不能用于真实导航或生存预测。

## 功能

- 秋日骤变、冬季风雪、雾中同行三种情境。
- 三种装备方案，重量、保温和通信能力有不同取舍。
- 三名队员分别计算体力、保温和伤势，速度受最弱队员影响。
- 逐次选择行进、避风、扎营、进食补水、照顾队员、补水、撤离或求援。
- 天气与事件由情境种子及模拟时间确定，可重复推演。
- 浏览器自动存档、逐步记录、任意一步回溯分支、原决策对比和 JSON 导出。
- 安全抵达、撤回山脚、救援完成或失去行动能力等结局。
- 响应式布局、键盘行动快捷键、减少动画偏好支持。

## 本地运行

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/games/aotai-sim/`。ES modules 需要 HTTP 服务，不能使用 `file://` 直接打开。

模型检查：

```sh
node --test games/aotai-sim/engine.test.mjs
```

## 模型边界

`energy` / `warmth` 等值均为 0–100 的游戏状态，不是体温或临床指标。救援等待时间是虚构游戏时间，不是现实响应承诺。天气趋势给出的未来气温仍使用当前节点海拔，前进后可能变化。死亡率、实际进山线路与真实事故人物未写入模型。
