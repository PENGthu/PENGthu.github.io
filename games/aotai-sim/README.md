# 鳌太 · 每一步 4.1 / 风雪之间

纯静态互动生存故事，发布在现有 GitHub Pages 的 `games/aotai-sim/`。无需依赖安装、构建、账号或 API 密钥。

## 玩法

- 三个故事情境：山间来信、风雪将至、循声而行。
- 16,000 元出发预算，三种背包，25 种逐件购买的装备与物资；可从配装示例开始自由调整。
- 14 个虚构故事节点，寻找失联者与低处绕行的实际路线分支，沿暴露山脊或低处前行的时间取舍。
- 25 种事件，包括同行者、野生动物、天气、涉水、方向判断、装备损坏、幻觉和延迟病痛。装备与电量会限制选项。
- 生命、体力、保温、精神、饱腹、补水，辅以湿衣、装备完整度、电量和负重；食物与饮水需要主动使用。
- 原创角色鹿宁与许舟：分享物资影响之后的告别；失联者需要物资、报告位置和救援接近，有不可逆的等待窗口。
- 可以沿实际走过的分支撤回；自身求援会固定位置，并继续消耗身体状态。抵达、撤离、获救与失败均有完整结局。
- 八项跨局成就，自动存档，同种子重玩，任意一步回溯分支、原选择比较和 JSON 记录导出。
- 具名人物对白、可逐句推进的对话、可点击观察的现场线索与选项回应预览。25 个事件及 14 个地点均有独立情境；阅读与观察不会推进游戏时间。
- 74 个事件选项各有独立动作情境、回应与取舍。每个地点的三种步速，以及休整、补给、使用与放弃物品，也先展示三段行动设想与对应前景插画，确认后才执行；条件不足的选项可阅读，不能提交。
- 暗色沉浸式界面：全屏山景主菜单、分步配装商店、装备插画、路线进度、六项彩色状态条与底部决策卡。
- 八幅原创环境（林地、雪山、溪流、羚牛、营地、石槽、湖泊、小屋）、三位原创人物立绘和 25 件代码绘制装备插画；无外部字体、追踪或网络游戏服务。
- 游戏占满窗口，页面不上下滚动。出发准备分三步；选项、物品与记录按窗口大小分页，休整、路线、反馈、复盘在独立面板中打开。

## 本地运行与检查

仓库根目录：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/games/aotai-sim/`。ES modules 需要 HTTP 服务。

```sh
node --test games/aotai-sim/*.test.mjs
```

规则测试覆盖预算、负重、不可变状态、条件选项、耗材、延迟病痛、路线与回溯、互信、救援时限、存档、完整故事、全部选项情境及预览不推进时间。页面启动检查使用 DOM 替身核对 HTML 与模块之间的连接，不代替真实浏览器视觉检查。

## 文件

`data.mjs`：物品、节点、原创剧情、配装与成就。
`engine.mjs`：确定性规则和状态迁移，无 DOM 或网络依赖。
`app.mjs`：界面、自动存档、背包、回溯与导出。
`ui.mjs`：窗口大小与分页规则。
`index.html` / `style.css`：页面、视觉样式与窗口布局。
`scenes.mjs`：完整情境、人物对白、条件回应与观察线索。
`cinema.mjs` / `cinema.css` / `scene-props.mjs`：人物、前景物件与对话舞台。
`choice-scenes.mjs` / `options.css`：全部事件选项、步速、休整与物品行动的独立情境及卡片。
`choice-scenes.test.mjs`：74 个事件选项、各地点步速、物品与休整情境的覆盖、不可变预览及失效条件。
`scenes.test.mjs`：场景覆盖、资源路径、人物状态与不耗时阅读的校验。
`icons.mjs`：界面图标与原创装备 SVG。
`assets/*.jpg` / `assets/characters/*.webp`：原创环境与透明人物立绘，随站点本地托管。
`assets/ART.md`：内置图像生成工具、最终文件路径及生成提示词记录。

UI v4 保留 v2 规则与现有存档。v2 使用独立存档键 `aotai-story-v2`，不会覆盖或误读旧版 v1 的存档。

## 制作依据与边界

玩法参考[小白薯《赛博徒步之生死鳌太线》](https://cyberhiking.com/about)的条件事件、逐件配装和分支叙事机制。视觉布局参考其主菜单、暗色商店、状态栏和故事选项。没有复制其程序、素材、对白或角色；使用原创山景与装备插画。

数值、天气、人物、救援等待时间与地点连接为虚构。保温和生命等为 0–100 游戏状态，不是临床指标。地点排列不构成真实路线，不提供真实导航，不预测生存概率。鳌太区域禁止违规穿越。
