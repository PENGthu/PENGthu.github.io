关于这场推演

先观察，再选择。

点击行动卡查看取舍，再点击「执行决策」。每步推进 20–60 分钟；天气、体力、保温、补给和队伍联系随时间变化。

  1. 保温和体力是每个人的状态；任一队员降到危急阈值，推演终止。
  2. 口粮、储水与饱食、补水状态不同。背包里有食物，不代表已经进食。
  3. 营地和避风处能减少暴露，移动会失去遮蔽。强风中的营地保护较弱，装备也会受损。
  4. 联系救援需要可用通信与电量；天气、移动位置会改变等待时间。
  5. 在复盘记录中点击「从此处重选」，可以回到同一个情境，观察不同决策的结果。

快捷键：数字 1–9 选行动，Enter 执行。进度自动保存在当前浏览器，也可以导出 JSON 复盘。

模型依据与边界

风险主题参考公开事故报道中的天气变化、失温、队伍走散和救援延迟。角色、路线、资源数值和事件均为虚构，模型不能预测真实山地生存结果。鳌太区域存在禁止擅自穿越的管理规定。
